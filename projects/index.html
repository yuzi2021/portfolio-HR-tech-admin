HR ↔ LMS Reconciler

Turning a repeated manual check into a systematic one

A browser-based tool that compares HR and LMS exports and flags records that may need investigation — missing accounts, leavers retaining access, permission mismatches and training-rule gaps — then generates a remediation report.

The focus is operational rather than compliance-driven. The tool does not try to decide whether something is a violation; it identifies the issue, gives the administrator enough context to investigate it, and makes a repeated manual check systematic.

It runs entirely client-side. The exports are read in the browser and never uploaded, so a routine administrative check does not become a data-transfer decision.

I built this for the kind of reconciliation problem a learning platform such as Docebo, and an engagement tool such as Peakon, create in day-to-day operations. I researched how these platforms handle the user and data lifecycle and where gaps appear — for example incomplete deprovisioning leaving active accounts for leavers, enrolment rules that do not reach staff who are already in a group, and manager and hierarchy data that does not sync automatically — then built a tool that flags exactly those cases.

This is my own project informed by that research; I have not used Docebo or Peakon directly.

SkillPath

Building, testing and troubleshooting a working system

Built as a University of London Django REST API project over a job-posting dataset: a data model, ingestion and validation, API endpoints and an automated test suite. It is now deployed and running, with a web UI over the data and interactive API documentation through Swagger and ReDoc — so the API can be read and exercised in the browser rather than only described.

What I found most useful was working through how the pieces interact — data ingestion, database behaviour, API requests, testing, user-facing behaviour — and diagnosing problems when they did not behave as expected. That is the part I would carry into an operations role: reproducing an issue, narrowing down where it actually sits, and confirming the fix.

I later hardened it with structured ETL, PostgreSQL, Docker and CI, and deployed it.

GDPR guide & staff workshop

Documentation and training for non-specialists

I created a practical GDPR guide and a staff workshop that translated complex requirements into usable guidance for people without a technical or legal background.
