HR ↔ LMS Reconciler

Reconciling HR and LMS exports without moving the data

I investigated how Docebo and Peakon handle the user and data lifecycle, and found the points where the two systems drift apart and create manual administrative work.

The result is a browser-only tool that reconciles an HR export against an LMS export and flags missing accounts, leavers who still retain access, permission mismatches and training-rule gaps, then auto-generates a remediation report for the person who has to act on it.

It runs entirely client-side. The exports are read in the browser and never uploaded, so a routine administrative check does not become a data-transfer decision.

SkillPath Navigator

Django / REST API for skills and learning paths

A backend built around a relational data model, with a CSV loader for bulk data, six API endpoints, ORM-based analytics queries and an automated test suite.

The modelling problem underneath it is the same one that sits under most HR systems: people, roles, skills and progress held as relationships that have to stay correct as they change.
