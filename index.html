HR ↔ LMS Reconciler

Turning a repeated manual check into a systematic one

A browser-based tool that compares HR and LMS exports and flags records that may need investigation — missing accounts, leavers retaining access, permission mismatches and training-rule gaps — then generates a remediation report. It runs entirely client-side.

The focus is operational rather than compliance-driven: identify the issue, give the administrator enough to investigate it, and make a repeated manual check systematic.

I built it for the kind of reconciliation problem a learning platform such as Docebo, and an engagement tool such as Peakon, create in day-to-day operations. I researched how those platforms handle the user and data lifecycle; this is my own project informed by that research, not experience with either tool.
